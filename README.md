# MedSBoX Pro

منصة مكتبة تطبيقات طبية ودراسية مع اشتراك يدوي وتفعيل عبر Telegram.

## تجربة المستخدم
- المكتبة العامة قابلة للتصفح والبحث بدون إنشاء حساب أو تسجيل دخول.
- الصفحة العامة تستخدم الهوية المعتمدة ونظام تصميم موحداً مع Glass UI مضبوط وقابل للقراءة.
- التنقل العام يتضمن حالة الصفحة الحالية، دعماً أفضل للوحة المفاتيح، وتنقلاً سفلياً محسناً على الهاتف.
- الضغط على أي زر تحميل ينقل المستخدم إلى صفحة الاشتراك والتفعيل.
- اشتراك Android السنوي: **$10 / year**.
- اشتراك Android مدى الحياة: **$25 one time**.
- الاشتراك الواحد يفتح الوصول إلى **100+ تطبيق Android** الجاهز للاستخدام، بحسب التطبيقات المنشورة في المكتبة.
- بعد اختيار الخطة يتم إنشاء جلسة Firebase مجهولة في الخلفية فقط عند الحاجة للأمان وربط طلب التفعيل؛ لا يرى المستخدم حساباً ولا يُطلب منه بريد أو كلمة مرور.
- التواصل والدفع والتفعيل يتم عبر حساب Telegram الرسمي، ثم يرسل المشرف كود تفعيل لمرة واحدة.

## تجربة v1.5 العامة
- Homepage: تسلسل بصري أوضح، CTA مباشر، بطاقات ثقة، وواجهة متجاوبة.
- Library: بحث وفلاتر أوضح، حالات تحميل/فراغ، وبطاقات تطبيقات محسنة.
- Offers: إبراز الحملات والتحديثات مع رسالة وصول للمشتركين.
- Apple Store: تسلسل أوضح للأجهزة والكتالوج والخطط مع استجابة أفضل للشاشات الصغيرة.
- Subscription: إبراز اختيار الخطة، مرجع الطلب، ومسار الدعم.
- Activation: نموذج أكثر وضوحاً وحالات تركيز ورسائل حالة أفضل.
- Shared shell: Header وtheme switcher وmobile quick navigation وfooter متناسقة.
- Accessibility: focus-visible، أهداف لمس مناسبة، ودعم reduced-motion.

## البنية
- `index.html`: الصفحة الرئيسية، المزايا، الاشتراك، Apple Store، وقنوات المطور/الدعم.
- `library.html`: المكتبة الحية من Firestore مع البحث والتصنيفات والتفاصيل.
- `payment.html`: صفحة الاشتراك Android ذات السعرين الثابتين ومسار Telegram.
- `activation.html`: إدخال كود التفعيل في جلسة مجهولة غير مرئية للمستخدم.
- `offers.html`: العروض والحملات الحية.
- `ios-store.html`: كتالوج iPhone/iPad منفصل ومدار من Admin.
- `admin.html`: لوحة التحكم للمشرف فقط.
- `css/design-system.css`: نظام التصميم الأساسي والرموز الدلالية.
- `css/public-experience.css`: طبقة تجربة v1.5 العامة.

## حماية البيانات
روابط Telegram الخاصة بالتحميل لا تُحفظ في بيانات الكتالوج العامة؛ توجد في مجموعات محمية مثل `appDownloads` و`offerDownloads` و`iosDownloads`. قواعد Firestore تتحقق من هوية المشرف والاشتراك الفعال وسلامة التفعيل وتمنع قواعد `allow=true` المفتوحة.

## إعداد المشرف
بعد إنشاء حساب المشرف في Firebase Authentication، أنشئ المستند:
`admins/<UID>`

```json
{ "enabled": true, "role": "admin" }
```

لا توجد طريقة عامة لإنشاء مشرف.

## نشر Firebase
1. ثبّت Firebase CLI وسجّل الدخول.
2. استخدم مشروع Firebase `medsbox-pro`.
3. انشر Hosting وFirestore Rules، وانشر Functions فقط إذا كان استخدامها مطلوباً في البيئة الحالية.
4. راجع روابط Telegram في كل تطبيق قبل النشر.

## ملاحظات تشغيلية
- إعدادات Firebase Web الظاهرة في JavaScript ليست مفاتيح خدمة سرية؛ الحماية الفعلية تعتمد على Authentication وFirestore/Storage Rules والوظائف الموثوقة.
- لا تضع Service Account أو مفاتيح خاصة في الواجهة.
- لا تضف تطبيقات أو روابط تنزيل لا تملك حق توزيعها.
- صفحة الاشتراك Android لا تعتمد على أسعار Firestore حتى لا يظهر سعر غير مقصود للمستخدم؛ الأسعار التجارية الحالية هي $10 سنوياً و$25 مدى الحياة.
